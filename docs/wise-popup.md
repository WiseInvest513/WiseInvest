# Wise 社群弹窗

投票活动已结束。主站保留原有今日精选，IPO 保留原有推荐弹窗；其余站点自动展示加入群聊。每次展示时记录时间，同一浏览器、同一站点 3 小时内刷新、重新进入、切换页面或打开新标签均不再自动弹出。导航中的手动入口不受间隔限制，手动打开也更新展示时间。到期后下次进入可再次自动展示，不在阅读过程中定时打断用户。记录优先保存在 localStorage，并有 sessionStorage 和页内回退；不涉及数据库。

主站保留原有今日精选内容及手动社群入口。ETF、Chain、SIM、HOLD、见证开户使用原有弹窗及二维码；VIP、Crypto 自动使用统一社群弹窗，IPO 只在手动加入群聊时使用。社群渠道以微信为默认，微信在左并展示二维码。登录、账户、后台及支付流程不自动打扰。

公共旧活动接口固定返回 enabled: false，旧管理接口返回 410。不读取或修改活动数据库；保留历史数据库迁移。

共享脚本变更可用 scripts/sync-wise-popup.mjs 同步各本地项目。

所有社群弹窗统一由 wise-popup.js 渲染，采用 CHAIN 的 340px、16px 圆角、绿色微信/蓝色电报标签与全宽二维码样式。原组件只保留导航/开关适配，不另行渲染弹窗。二维码使用各站本地的草料图片.png 与电报图片.png；主站今日精选、IPO 推荐保留原内容并统一容器样式。
