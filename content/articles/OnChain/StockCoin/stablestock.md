## 一、先选择传统证券或稳定币产品路径

想参与港股 IPO，既会遇到传统券商账户，也会看到支持稳定币的产品入口。这一篇从已有链上资金的读者出发，梳理 **StockCoin 的认证、转入、申购和退出**，同时把“自己申购某只新股”与“持有策略产品份额”分开。

传统路径通常涉及银行账户和证券账户。先确认自己的开户资格、账户允许的资金用途及同名转账要求，再选择中转工具；Wise、iFAST、StarryBlu 并不是同一种银行账户，资金也不一定可以沿图中任意方向转移。

## 二、产品类型与协议边界

StockCoin 当前官网展示股票相关交易、衍生品与 IPO / Earn 入口。同一品牌中的不同模块，可能采用不同的账户、资产和协议安排，不能统一解释成“都买到了股票”。

| 产品入口 | 先取得哪些信息 |
| --- | --- |
| 股票或代币化股票 | 持有的资产名称、发行或托管安排、分红及赎回权利 |
| 股票衍生品 | 合约标的、保证金、资金费用和强平条件 |
| 单只 IPO / Pre-IPO | 实际认购权益、分配与退款规则、上市或退出限制 |
| IPO Earn 策略 | 份额确认、净值、费用、锁定与赎回条件 |

### 不用一个页面替代所有产品协议

当前[使用条款](https://stockcoin.ai/en-us/terms-of-use)包含链上界面和钱包相关描述，并对某些代币化股票列出单独的资格要求；这些内容不能自动证明旧图中每个申购模块的法律结构相同。[合规披露](https://stockcoin.ai/en-us/compliance)可作为查找合作与资产支持说明的入口，但仍需取得本人所用产品的正式文件。

因此，申请前应保存**实际服务实体、本人适用地区、资产权利及退出条款**。某个产品文件看不到，不能直接推断产品不存在，也不能反过来当作已完成核验。

## 四、链上转入与到账核对

### 先在自己的接收账户取地址

进入本人账户的充值入口，核对当前接受的币种与网络。旧图以 **USDT / BSC** 为例，本次操作仍需取得实时地址，检查最低到账额、费用和附加标签要求。

![在 StockCoin 选择 USDT 和 BSC 网络，获取充值地址](./6.jpeg)

再打开本人转出账户，例如原图中的币安，进入链上提现。选择相同币种和网络，粘贴实时地址，或扫描**本人账户本次充值页**的二维码。不要扫描文章中的历史收款地址。

提交前核对地址首尾、网络名称、数量与净到账金额。首次先用满足最低要求的小额验证，并保存转出记录和交易哈希。

![在币安 APP 中选择 USDT、BSC 网络，并提现到 StockCoin 地址](./7.png)

### 到账之后，核对三种状态

1. **发送状态：** 转出平台是否已受理、是否已经广播到链上。
2. **链上状态：** 哈希是否有效，网络和接收地址是否匹配，确认是否完成。
3. **账户状态：** StockCoin 是否记账，币种和净额是否正确，余额是否可以用于目标产品。

链上成功而账户未记账时，先保存哈希、币种、网络和金额给官方支持核查，不因焦急连续重复充值。不要把 USDT 转入、兑换为产品结算单位和获得策略份额当成同一步。

## 五、现金或融资申购的检查顺序

原界面从 **Super PRO** 进入 IPO / Pre-IPO 相关区域。下图的标的是旧记录，不代表目前仍可申购；应重新检查完整名称、代码、发行文件、截止时间与具体权益。

![进入 Super PRO 后，在 IPO 专区选择具体标的并点击申购](./8.jpeg)

### 提交前，先算需要占用多少钱

**现金申购**要确认足够的可用资金、币种转换和扣款时间；**融资申购**除了保证金，还要看借款规模、利率、计息天数、追加资金要求与归还安排。没有获配，也可能已经产生申请费或融资成本。

旧图该笔订单显示约 **5 万多港币**的资金要求与 **50 港币**手续费，只是历史样本。它们不能推广为全部标的的门槛或总成本。

![选择申购方式、输入申购数量后提交申购](./9.jpeg)

### 提交后，按订单生命周期核对

| 节点 | 应检查的结果 |
| --- | --- |
| 提交申请 | 标的、现金或融资方式、手数、费用和订单编号正确 |
| 申请受理 | 状态已受理，冻结金额与订单说明一致；不能把扣款当成中签 |
| 公布分配 | 获配数量、实际扣款、融资余额及未获配退款分别确认 |
| 上市或可交易 | 查看真实持仓及允许交易的时间，确认卖出渠道与费用 |
| 退出之后 | 核对成交、结算、还款及可提余额，保存完整记录 |

对于 Pre-IPO，还应在提交前确认没有如期上市时怎么办、份额是否能转让以及最长可能锁定多久。未来上市安排不是确定的退出日期。

## 六、IPO Earn 的份额、锁定与赎回

原稿把这类产品称为“理财打新”，并用集合打新作类比。类比只能帮助理解资金集中运作：**把配号放在一起，不会让所有人一起中签**，更不会提高单个配号自身的中签概率。是否分享已实现损益，要看合法有效的具体安排，不能用这张旧图解释 StockCoin 的产品合同。

![旧版集合打新概念图，不代表所有参与者中签或 StockCoin 的合同结构](./10.jpeg)

### 先确认购买的是策略份额

本次于 **2026 年 11 月 7 日**读取的[官方 IPO Earn 页面](https://stockcoin.ai/zh-cn/ipo/earn)描述的是 USDS 策略份额。页面列明合格投资者与 KYC 条件，支持 USDT / 可用 USDS，最低 100；USDT 投入会先转换为 USDS。份额确认后锁定 **30 天**，净值可能亏损；符合协议的正收益收取 **15% 业绩分成**，另有申购、赎回等费用。页面还说明认购后同一身份不能再参与港股打新，须先核对自身安排。

**赎回时效目前不能写成一个确定数字。** 同页流程区写“无进行中打新时 T+1 到账”，FAQ 则写“通常 T+5 结算”。两处口径不一致，参与前应取得适用于本人订单的锁定起算、结算与到账说明；不能按较快的一项安排近期用钱。

旧图中的 **600U** 是当时那笔操作金额；页面有最低金额，不代表只能按 100 的整数倍申购。

![StockCoin 策略理财旧界面：输入 600U 的历史记录](./11.jpeg)

### 按份额记录判断结果

文字流程可以分成四步：**核对资格与协议 → 确认扣款资产及费用 → 查看确认份额和锁定结束时间 → 解锁后核对赎回与到账**。提交申请不等于份额已经确认；看到净值上涨，也不代表同样金额已经可提现。

![理财打新策略旧说明：历史展示不代表未来收益](./12.jpeg)

观察结果时同时记录投入、确认份额、净值日期、费用、锁定天数和已实现损益。预期年化与累计历史收益不能当成固定利息，策略筛选也不会消除新股破发或市场下跌。

## 七、资金退出与异常处理

退出前先确定自己持有的是可交易资产、未结算订单，还是仍在锁定的策略份额。它们对应不同的处理路径：

- **单只申购：** 先查获配、退款和融资余额，再看卖出与结算安排。
- **策略份额：** 先查锁定结束时间和可赎回数量，再查赎回是否受理、结算币种与到账状态。
- **平台可用余额：** 按当前提现页面核对可提金额、支持网络、费用及本人接收地址。

“有余额”不等于全部可提现。出现差额时，用订单号、费用明细和链上记录定位，不随意补转所谓解冻费。稳定币脱锚、平台运营、资产托管、合约与市场风险也应分别考虑。

StockCoin 的多个入口需要各自核对。先确认**本人资格与产品权利**，再走认证、转入、订单核对和退出流程；不要仅凭股票名称或“理财”字样判断它与传统证券、存款相同。
