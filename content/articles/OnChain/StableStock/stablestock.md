## 一、先认识 StableStock 解决的需求

手里的资金以稳定币为主，却希望了解股票与 IPO，最先遇到的问题往往是账户和资产结构。StableStock 提供了连接稳定币与股票相关业务的入口，本文用旧操作记录介绍注册、入金和申购，再把费用与风险单独说明。

不需要港卡的操作入口，不等于不需要符合开户条件；页面显示股票名称，也不足以证明你在所有模块中都直接持有同样的证券权利。

## 二、产品介绍：证券账户与链上代币要分开看

原稿介绍了 StableBroker、sStocks，以及 Vault / Swap 等模块。它们分别涉及股票交易通道、代币化资产与策略或交换服务，不能混为一个账户。

| 模块或问题 | 使用前需核对的内容 |
| --- | --- |
| 股票交易通道 | 实际开户/清算机构、账户归属、持仓证明及转仓安排 |
| 代币化股票 | 发行主体、底层资产支持、持有人权利、申赎资格 |
| 收益策略与交易池 | 资产如何运用、损失由谁承担、合约和流动性风险 |
| 服务资格 | 居住地、证件、税务资料与各模块独立的使用限制 |

平台背景和合作机构可以作为进一步研究的线索，不能替代正式协议。普通证券和代币交易也都可能产生价差或滑点；不使用“无滑点”“无隐形成本”这样的绝对描述。

如果上述信息无法从当期文件中确认，先暂停入金。下面的截图和历史费率用于认识流程，不替代当前产品文件。

## 六、费率

下面保留原稿费率表作为**历史费用样本**。本次复核未能读取该官方费用页，不能确认表中金额仍适用；交易前需要重新取得 [官方费率说明](https://stablestock.gitbook.io/ss/concepts/stablebroker/fee) 或账户内完整报价，不能只按这张旧表估算实付。

理解费用时，可以先拆成平台费用与通道/监管费用两部分；以下数值均沿用原稿历史记录：

- **① StableStock 自己的服务费**：不管买还是卖，都按交易金额收 **0.1%**
- **② 上游通道和监管费用**：直接转给券商、交易所、FINRA、香港政府等（代收代付），金额很低、完全透明

### 美股费用明细

| 费用项目 | 金额 |
|----------|------|
| StableStock 服务费 | 交易金额 × **0.1%** |
| 上游经纪商平台费 | $0.005/股（每笔最低 $1） |
| FINRA Trading Activity Fee（仅卖出） | 约 $0.000166/股 |
| Settlement Fee（结算费） | $0.003/股 |

按股计费与订单金额、股数有关，不能只凭“1 万美元”就算出完整成本。还要核对最低收费、卖出费用和当期适用费率。

### 港股费用明细

| 费用项目 | 金额 |
|----------|------|
| StableStock 服务费 | 交易金额 × **0.1%** |
| 上游交易佣金 | 0.02%（最低 HKD 15） |
| 印花税（香港政府收） | **0.1%** |
| 交易所交易费 + 结算费 + 其他监管费 | 合计约 0.012% |
| 上游平台费 | HKD 2 / 订单 |

港股涉及不同收费项目及适用范围。计算时使用具体证券和当期费率，不把原稿合计比例当作所有订单的统一费率。

### 如何自己估算一次买卖

先列出买入金额、股数和币种，分别计算平台费、按股费、最低收费及适用税费，再对卖出侧做一次计算。最后加上换汇、链上和提现费用；买卖价差与滑点另行观察。

只知道交易金额，不足以算出“买卖一轮固定 23 美元”这样的答案。订单报价和成交账单，才是核对实际支出的依据。

## 七、注意事项：不能只看资金进得去

注册前核对资格与真实资料，入金前核对资产保管与出金规则，申购前核对费用和锁定安排。股票可能下跌、IPO 可能破发，链上资产还叠加发行、合约及流动性风险。

CRS 与税务义务取决于实际实体、账户及税务居民身份，不能由稳定币入金或平台名称推断“不用申报”。费用页或合同无法确认时，先把这些问题问清楚。
