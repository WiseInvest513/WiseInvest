## 一、ChatGPT 订阅买的是什么？

ChatGPT 是 OpenAI 提供的 AI 助手。你可以在同一个账户里问问题、修改文章、分析上传的文件、讨论代码，并使用账户开放的其他工具。免费版可以先体验；当你经常使用，开始碰到用量限制，或需要更完整的工具访问时，再考虑付费套餐。

本篇以 **ChatGPT Plus 的网页订阅**为例。2026 年 11 月 16 日核对官方说明时，Plus 的美元标准价格为 **20 美元／月**，提供比免费版更高的使用额度，以及更广的模型与工具访问。具体可用模型、工具和额度会调整，可以在自己的账户里查看。[ChatGPT Plus 官方说明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)

这里的会员是在你自己的 ChatGPT 账户上升级。**它不包含单独计费的 OpenAI API 用量**：如果你的目标是给某个第三方程序填写 API Key，那是开发者平台的计费事项，不应在这里买完 Plus 就以为已经充好 API 余额。

套餐页还可能展示其他个人或团队方案。本篇先把 Plus 开通流程讲清；付款前认准你选择的套餐、计费周期和结账总额。网页可能显示当地货币和税费，不能机械地把所有结账金额都当成恰好 20 美元。[OpenAI 多币种结账说明](https://help.openai.com/en/articles/10421635-multicurrency-billing)

## 二、已经有卡，现在准备这几项

Wise 近期使用 Bybit、Gate 和 MP 的卡成功订阅过 AI 产品。如果你已经有其中一张可用卡，可以先沿用；这个反馈未拆分每张卡对应的产品和卡种，单笔付款仍看实际受理结果。

| 要准备什么 | 去哪里找 | 做到什么程度可以继续 |
| --- | --- | --- |
| 本人 ChatGPT 账户 | [chatgpt.com](https://chatgpt.com/) | 能登录，并认得这是自己要升级的账号 |
| 卡号、有效期、CVV / CVC | 发卡 App 的卡片详情 | 能显示完整资料，卡片未冻结或过期 |
| 持卡人姓名 | 卡片详情或发卡方记录 | 按登记姓名填写，不用网站昵称代替 |
| 账单地址 | 发卡 App、银行留存资料或卡方客服 | 知道这张卡实际登记的国家、街道、城市等字段 |
| 卡片可用余额 | 卡片消费账户 | 能覆盖结账总额和卡方可能收取的费用 |
| 验证方式 | 发卡方绑定手机或 App | 能接收验证码或确认支付验证 |

**地区条件也要在付款前确认。** OpenAI 要求服务所在地与发卡地区符合支持范围；当前支持名单未列中国大陆。境外卡的开通本身不会改变 ChatGPT 的服务资格。[支持地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)、[付款条件](https://help.openai.com/en/articles/7232916-why-was-my-credit-card-declined)

还没卡，或者不知道账户里的资金如何变成卡片余额，可以先看选卡篇及对应开卡教程：

## 三、进入官网，按这个顺序选择 Plus

下面这张图把两个产品的入口放在一起，订 ChatGPT 时看上面一行。**这是根据官方帮助整理的流程示意，按钮名称用于定位，不是实际账号截图。**

![ChatGPT 与 Claude 官方订阅入口流程示意：ChatGPT 从头像进入 Upgrade Plan，再选择 Get Plus；Claude 从 Settings 进入 Billing](/images/articles/ai-subscription/subscribe-route.webp)

### 第一步：打开并登录 ChatGPT

在浏览器打开 [chatgpt.com](https://chatgpt.com/)，登录自己以后要长期使用的账号。确认头像菜单里的账户身份；如果日常有多个邮箱，不要顺手给另一个账号开通。

本文走网页付款。通过 iPhone 或 Android 应用订阅时，付款和管理由 App Store 或 Google Play 处理，入口与本文不同。已经在手机商店订阅的人，先确认原订阅状态，再决定是否另走网页路径。

### 第二步：点击头像，找到 Upgrade Plan

打开个人头像／账户菜单，选择 **Upgrade Plan（升级套餐）**。根据语言与界面版本，也可能显示“升级”或类似文字。官方帮助给出的主路径是 **头像 → Upgrade Plan → Get Plus**；不用去开发者平台寻找 API 充值入口。[官方开通步骤](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)

### 第三步：选择 Get Plus，检查订单

在套餐页找到 **Plus**，点击 **Get Plus／获取 Plus**。进入结账页后，先看三项：

- **产品名称**是否是你要的 ChatGPT Plus。
- **计费周期**是什么，是否自动续费。
- **本次总额与币种**是多少，有没有额外税费。

确认之后再填写银行卡。若页面未提供该套餐，或显示地区不可用，先处理账户和服务条件；不要把另一个产品的结账页面当作 Plus 页面来付款。

## 四、卡号、有效期和姓名分别怎么填

网页信用卡／借记卡付款一般会出现下面这些字段。它们都从**你准备使用的同一张卡**取值，不要从两张卡混合抄写。

| 结账页字段 | 中文含义 | 填写方法 |
| --- | --- | --- |
| Card number | 卡号 | 在发卡 App 显示完整卡号后填写；不是账户 UID，也不是钱包地址 |
| MM / YY | 到期月／年 | 按卡片显示的月份和年份填写，留意月份在前 |
| CVC / CVV | 安全码 | 填卡片详情提供的安全码；不是支付密码或短信验证码 |
| Name on card / Cardholder name | 持卡人姓名 | 与这张卡登记的姓名一致；英文／拼音按卡方资料填写 |
| Email | 账单邮箱 | 填自己能收邮件的邮箱，核对是否为本次使用的账户 |

部分结账组件会出现保存付款信息或 Link 的选项。按页面选择是否保存即可；不要把自动填入的旧卡、旧姓名和本次卡片资料混用。确认下一部分的地址后再提交。

## 五、账单地址：先查资料，再逐项对应

**账单地址是这张支付卡对应的账单资料，不是随便找一个城市和邮编配起来就行。** 先去卡片详情、Billing address 或银行留存资料中查看；看不到时向发卡方确认该卡的填写要求。

有些虚拟卡会显示专用账单资料，有些不会。以 MP 为例，官方不同教程对“App 是否提供地址”的表述并不一致，因此不能保证每个账户都能复制到一组地址。找不到时，向卡方确认并按自己的真实资料填写，而不是自己补造一个美国身份。[MP 订阅说明](https://help.mp.net/zh-CN/articles/13333665)、[MP AI 订阅帮助](https://help.mp.net/zh-CN/articles/16392598)

![账单地址字段与填写依据对应示意：姓名、国家、街道、城市、州和邮编从卡片或银行账单记录核对](/images/articles/ai-subscription/billing-fields.webp)

| 页面字段 | 该填哪一项 | 常见填错 |
| --- | --- | --- |
| Country / Region | 此卡账单资料对应的国家或地区 | 见到英文表单就一律选美国 |
| Address line 1 | 门牌号、街道等主要地址 | 把城市、州、邮编全塞进这一格 |
| Address line 2 | 公寓、楼层或单元号；没有可留空 | 为了填满而编造一个房间号 |
| City | 同一地址中的城市 | 与州或邮编属于不同地区 |
| State / Province | 同一地址中的州或省；按下拉选项选择 | 把城市名填到州名栏 |
| ZIP / Postal code | 对应这条账单地址的邮编 | 从别的地址随手复制一个邮编 |

**国家、街道、城市、州和邮编应来自同一份有效账单资料。** 页面国家如果预填错了，就检查是否可以改成正确国家；若不支持正确资料，先联系发卡方或商户。不能为了迁就预填值，另造一套地址。

如果不熟悉英文地址，可以打开[美国地址生成器](https://www.meiguodizhi.com/)认识字段。按页面选择美国地址后，查看同一条记录里的 Street、City、State 和 ZIP，理解它们分别对应上表的哪一栏。

下面保留原教程的生成器截图，**只用于识别字段位置**。例如 City 是城市，State 是州，ZIP 是邮编；页面同时出现的姓名、生日、电话和邮箱并不是你的资料。生成器把字段放在一条记录里，也不代表它已验证了这条地址真实有效。

![美国地址生成器旧界面示例，仅供识别街道、城市、州和邮编字段，图中身份和地址不得当作本人账单资料提交](/images/articles/ai-subscription/address-generator-reference.webp)

实际付款时，回到卡片或银行确认的资料填写。**生成器适合学习格式，不能代替银行账单地址，也不能作为居住或身份凭证。** 新加坡发行、美元结算或显示英文表单，也都不自动等于“必须填写美国地址”。

## 六、确认付款，成功后就可以使用

核对套餐、周期、总额、卡号和账单资料后，点击结账页的**订阅／确认付款**按钮。如果银行弹出短信或 App 验证，按提示完成。

**付款成功、账户显示 Plus 后，订阅就完成了，可以返回聊天页面使用。** 保留收据即可；这篇不再展开付款后的操作。以后不续费时，应在原购买渠道取消订阅，不能用清空卡片余额代替取消。

如果没有完成付款，按报错位置处理，不必从头重新办卡：

| 卡在哪里 | 下一步 |
| --- | --- |
| 卡号／有效期报错 | 回卡片详情核对整组信息，并确认卡已启用 |
| 余额不足 | 查卡片可消费余额，补足订单总额与卡方费用 |
| 要求验证／authentication required | 完成银行短信或 App 的 3DS 验证 |
| 地址错误或拒付 | 核对登记地址与发卡地区；仍失败时联系卡方查询拒绝原因 |
| 没有升级入口／地区不支持 | 核对产品的服务条件，不把更换卡片当成解决所有问题的方法 |

这些处理方向来自 [OpenAI 付款失败帮助](https://help.openai.com/en/articles/7232916-why-was-my-credit-card-declined)。卡片已扣款但账户未升级时，先查原账号和订单状态、联系官方支持，不要立即再买一遍。
