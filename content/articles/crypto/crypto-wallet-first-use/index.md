交易所里已经能看见余额，为什么还要装钱包？因为你可能希望自己掌握签名权限，或者需要使用链上应用。但接过控制权，也意味着接过备份和恢复的责任。

这一课以 MetaMask 的**助记词模式、Ethereum 网络上的普通账户**为例。从空钱包开始，先弄懂恢复，再考虑收发币。你可以先读完全部流程，不必马上转入资产。

## 一、先决定为什么需要自己保管

如果当前目标只是理解现货买卖，可以先把账户和订单学会。自管钱包适合需要自己控制链上账户、接收资产或使用链上应用的人；它不会自动消除价格波动、诈骗或操作失误。

软件钱包、硬件钱包和智能账户的密钥与恢复方案不同。硬件钱包把签名放在专用设备中，但仍需检查签名内容与接收地址。本篇先把一种明确的模式走清楚，不把所有叫“钱包”的产品当成同一种东西。

MetaMask 当前也提供社交账户等创建方式。它们的恢复依赖不同，不能只记住“密码丢了就用助记词”而忽略自己实际选择的模式。下面仅沿着自行保存助记词这一条线学习。[MetaMask 钱包安全模型](https://support.metamask.com/start/user-guide-secret-recovery-phrase-password-and-private-keys/)

## 二、四种信息，分别能做什么

| 信息 | 在本篇模式中的作用 | 是否交给收款人或客服 |
| --- | --- | --- |
| 收款地址 | 标识某个网络上的收款账户 | 收款时可提供，但仍要注意隐私与网络 |
| 钱包设备密码 | 解锁本机钱包数据 | 不提供；换设备时仅知道这个密码不足以恢复 |
| 助记词 | 恢复由这一组词派生的账户 | 不提供，也不输入领取奖励或客服网页 |
| 单个账户私钥 | 控制对应账户 | 不提供；不能代替整个钱包的全部备份 |

记住一个区别：地址可以让别人给你转账，助记词可能让别人把你的资产转走。更改设备密码，并不会让已经泄露的助记词失效。

本课不展示任何可用助记词、私钥或收款二维码。学习不需要复制一套别人的秘密，真正使用时必须由本人可信的钱包环境创建。

## 三、从官方下载并创建一个空钱包

从 [MetaMask 官网](https://metamask.com/)进入下载，再核对对应商店的应用或扩展。不要因为搜索结果里有相同狐狸图标，就认定是官方版本。官方的[安装说明](https://support.metamask.com/start/getting-started-with-metamask/)给出了浏览器与手机入口。

安装后按下面的顺序检查：

1. **选择创建新钱包。** 如果你已有钱包且希望恢复，应走导入已有钱包；创建新钱包不会找回原来的地址。
2. **确认创建方式。** 本课选择自行保存助记词的方式。若界面走的是社交登录，先阅读该方式的恢复说明，不把两套步骤拼在一起。
3. **设置本机解锁密码。** 保持独立，并理解它保护的是这次安装的访问。
4. **按应用提示完成备份。** 由本人在私密环境中记录全部词与顺序，完成应用内的核对。屏幕共享、录屏和相机都应关闭。
5. **查看空账户。** 记下当前选中账户的公开地址与网络名称，用于后面核对；此时余额为零是正常起点。

创建步骤可能随版本变化，核对依据是自己选择的模式与生成的账户，而非某个按钮永远在右下角。[MetaMask 创建钱包说明](https://support.metamask.com/start/creating-a-new-wallet/)

## 四、入金以前，核对备份与恢复

离线备份要解决三件事：完整、可读、不会与设备一起失去。按顺序抄写，检查拼写与编号；考虑防水、防火、遗失和未经授权查看。不要为了“隐藏”而随意打乱词序，过几个月自己也可能无法恢复。

不要截图后同步到相册，不发邮箱，不把助记词放进在线翻译、AI 对话或所谓校验网站。任何收款、领奖或连接应用都不需要你把整组助记词交出去。[Ethereum 钱包安全指引](https://ethereum.org/security/)

理解恢复流程时，可以先阅读官方步骤：在可信的官方安装中选择“已有钱包”，按原顺序输入本人助记词，设置该安装的密码，再核对恢复出的公开地址。[MetaMask 恢复说明](https://support.metamask.com/configure/wallet/how-to-restore-your-metamask-wallet-from-secret-recovery-phrase)

**不要为了演练删除唯一的可用钱包。** 若要验证恢复，先保持原安装完好，只在自己确认可信的独立环境中对尚未入金的新钱包完成核对；不确定设备或备份是否可靠，就停在空钱包阶段。恢复出的账户地址一致，才说明找到了预期账户；仅仅“导入成功”还不够。

另外，后来单独导入的私钥账户、另一组助记词账户或连接的硬件账户，未必由当前这组词恢复。把钱包界面里的“账户列表”与“同一套备份能恢复哪些账户”分开理解。

## 五、第一次收币，先把网络和地址对上

先在接收钱包选择本次要使用的网络与账户，再复制收款地址。发送端同时确认：支持相同网络、资产版本正确、地址完整匹配，以及必要的备注和最低金额条件。

本课只以 Ethereum 为例。某些网络可能显示相同样式甚至相同字符的地址，这并不表示资产会自动出现在另一条网络。切换钱包里的网络，只改变你查看与操作哪条链，不会帮你跨链搬币。

从交易所提到钱包时，核对提币费用与净到账。先做满足平台最低金额条件的小额核对，收到后再决定是否继续；不要把“先试一点”理解成可以忽略最低限额。

收币完成后，检查链上交易的网络、接收地址、资产与数量，再查看钱包余额。钱包未自动展示代币时，应通过发行方和所用网络的可靠资料核对合约身份，再处理显示问题；不要从陌生人的消息里复制一个同名代币合约。

## 六、第一次发送，给网络费留出空间

收到 USDT 不代表已经具备继续转出的全部条件。对本课的普通 Ethereum 账户，发送代币通常需要该网络上的 ETH 支付 Gas；只有交易所里的 ETH，或另一条网络上的余额，都不能直接替这次交易付费。智能账户、代付服务等有不同安排，需要另读具体规则。[Ethereum Gas 说明](https://ethereum.org/developers/docs/gas/)

在钱包发送页逐项核对：接收方从哪里提供地址，目标平台是否支持本次网络与代币，发送数量和预估费用是什么。普通转账不需要为了“收款验证”先给陌生合约无限授权。

假设钱包有 0.01 ETH，要发送 0.003 ETH，钱包显示预计费用 0.0002 ETH，则预计总支出为 0.0032，预计剩余 0.0068 ETH。数字仅用于算术，实际余额要以最终手续费与链上结果复核。

发出以后查看交易哈希和状态。等待中不等于失败，链上执行失败也可能消耗已经使用的 Gas；不要因为结果没立刻变化就连续重复发送。普通已确认的链上转账不能像未成交的现货挂单那样撤销。

如果接收方是交易所，链上成功后还要等待平台自己的充值记账；这时沿着上一课的发送记录、链上记录、接收记录三段排查。

## 七、恢复后看不到余额，怎样排查

恢复的是控制账户的能力。资产记录仍在对应网络上，不会因为换手机就搬到新设备里。

| 现象 | 先核对什么 |
| --- | --- |
| 地址与原来不同 | 是否导入正确助记词，是否选中正确账户；是否属于另行导入的私钥账户 |
| 地址相同但余额为零 | 当前网络是否与原转入网络一致 |
| 原生币看得见，某代币看不见 | 链上记录、代币合约身份，以及钱包的代币显示设置 |
| 原来有多个账户，恢复后只有一个 | 哪些由同一助记词派生，哪些需要另行恢复或重新连接 |
| 链上显示资产已经转走 | 查看交易详情并排查授权与密钥安全，不能仅当作显示故障 |

MetaMask 的[恢复后添加缺失账户说明](https://support.metamask.com/configure/accounts/how-to-add-missing-accounts-after-restoring-with-secret-recovery-phrase)区分了派生账户与另外导入的账户。具体自动恢复行为会变化，公开地址的核对比账户昵称更可靠。

## 八、入金前的三道练习题

**手机丢失，但记得钱包密码。能否只靠密码在另一台手机恢复？**

在本课的助记词模式中不能。需要原助记词及适用的账户恢复资料；密码主要用于原安装的解锁。

**钱包里有 Ethereum 网络上的 USDT，但没有 ETH。是否一定能普通转出？**

不能这样假定。先核对该网络的 Gas 资产和钱包当前功能；本课的普通发送需准备可支付费用的 ETH。

**钱包切换到另一网络后，同一个地址显示余额为零，是否资产消失？**

先回到原网络查询。地址相似或相同，不等于不同网络共享同一份资产余额。
