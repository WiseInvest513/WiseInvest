## 一、认识 BIT：账户与产品区别

哈喽大家好，这里是 WiseInvest，我是你们的老朋友 Wise！

今天想和大家聊一个最近我自己也在研究的产品：**BIT**。很多朋友最早只是买 BTC、ETH，后来开始接触稳定币、链上资产、RWA，手里的资金也逐渐以 USDT、USDC 的形式留在交易平台和钱包里。

这时一个实际问题就来了：**如果想拿一部分稳定币配置美股，比如 NVDA、MSFT，或者长期定投 QQQ、SPY，资金该怎么进去？**

传统路径其实并不复杂，但操作起来确实比较折腾。你需要先考虑资金怎么从交易所或钱包转出来，之后可能还要换成美元，再通过银行账户汇款到证券账户。中间涉及多个账户、汇款路径、到账时间和汇率成本。对于已经习惯使用 Crypto 产品的人来说，这个流程并不算轻便。

当然，传统券商有自己的优势，专业交易工具、全球市场覆盖和成熟的证券服务都很完善。长期资产配置应该根据资金来源、投资需求和账户条件来选择工具。

如果一个人本来就主要使用 USDT、USDC，希望减少进入美国证券市场前的资金转换步骤，BIT 就是可以研究的一个入口。

先说明一个关键点：本文介绍的是**独立开立证券账户后，交易美国市场的美股正股及 ETF**。它和单纯在链上买一个跟踪股票价格的代币，产品结构并不相同。

如果你的目标是长期配置美股正股，或者用稳定币定投 QQQ、SPY，那么这类产品确实值得研究。

### 1、BIT 的前世今生

BIT 原名 Matrixport。Matrixport 于 2019 年成立，2026 年 3 月 20 日正式启用 BIT 作为新的品牌名称。根据官方介绍，此次更名是品牌与业务定位的升级，原有账户和服务不需要用户因为更名而重新操作。

过去大家更多从数字资产交易、托管、资产管理等角度认识 Matrixport。更名后的 BIT 继续拓展数字资产与传统金融资产之间的连接，其中就包括美股证券业务。

所以，如果你之前听过 Matrixport，BIT 就是它现在使用的新品牌名称。

### 2、BIT 美股账户买到的是什么？

链上股票代币、交易所发行的代币化证券，以及传统券商账户，都可能让用户获得美股价格敞口。它们看起来都能跟着 NVDA、AAPL 或 QQQ 的价格变化，但**法律结构、持有权益、清算托管和交易机制**可能完全不同。

BIT 官方披露，其美股业务支持交易美国上市普通股，并采用独立的证券账户开户和 KYC 流程。官方产品介绍将其定位为真实美股交易，而非链上股票代币。

BIT 的美股业务采用 **Omnibus Introducing Broker（综合账户介绍经纪商）**架构，可以按下面的路径理解：

1. 用户通过 BIT 前端完成开户、KYC、交易操作和账户查询。
2. BIT 将订单引入美国持牌经纪及清算体系。
3. 美国持牌清算机构负责相应交易清算及证券托管。
4. BIT 在前端管理客户身份验证、合规流程及账本记录。

BIT 官方披露的底层合作机构包括 Clear Street、RQD CLEARING, LLC 和 Atomic Vaults Securities, LLC。具体合作安排、账户权益和托管结构，应以当前官方披露及用户签署的账户协议为准。

> **先理解账户结构：**客户资产在清算经纪商层面以综合账户形式持有，用户的受益权益及具体权利安排需要结合账户协议理解。这不等于每个用户都在美国清算机构拥有独立登记的个人账户。

BIT 官方产品介绍称，用户可以享有相应股东权益，包括股息分红和投票权。具体适用范围和行使方式，应以证券账户条款及实际公司行动安排为准。

### 3、BIT 的核心优势在哪里？

**稳定币资金入口。**BIT 官方支持 USDT、USDC 入金和出金。对于本身就持有稳定币的用户来说，可以减少先把稳定币转回银行体系、再换汇汇款的步骤。

**美国上市证券。**BIT 官方披露支持美国上市普通股，并提供主板股票及 ETF 交易。用户可以研究 NVDA、AAPL、MSFT，也可以关注 QQQ、SPY 等指数 ETF。

**加密资产与证券账户衔接。**用户可以在同一平台生态内处理加密资产和证券资产，减少多个平台之间反复切换。

**多种开户和入金方式。**BIT 提供 App 和网页端证券开户，并支持稳定币入金、美元银行电汇及符合条件的证券转仓。不同方式的到账时间和费用不同，具体看后续操作说明。

### 4、合规与 CRS：不要把账户架构误解成免税或匿名

BIT 美股业务的运营主体、牌照所在地、美国清算机构、用户的税务居民身份，是几个不同层面的问题。

BIT 官方披露，美股业务运营主体为 Matrix Gelephu Pte. Ltd.，持有不丹格勒普正念之城（GMC）金融服务牌照，并通过美国持牌清算机构处理证券交易清算及托管。运营主体与许可业务可在 GFSO 金融机构名录中查询。

但这并不意味着用户可以因此免除税务申报义务，也不能把它宣传成“无 CRS”“匿名账户”或“规避税务信息交换”的工具。

CRS 是否适用、账户信息是否需要申报或交换，要结合账户实体、相关司法辖区的法律安排、账户性质和用户税务居民身份判断。用户仍需按照自身税务居民所在地的法律履行申报义务。

我建议大家开户之前，认真阅读账户协议、隐私及税务声明。涉及个人税务判断的，咨询专业税务人士。

建议提前准备：

1. **有效护照或国民身份证**，具体证件类型以账户申请页面及适用地区要求为准。
2. **最近六个月内的居住地址证明**，例如银行账单、公用事业账单等，具体以页面要求为准。
3. 本人职业、收入、资产、资金来源等信息。
4. 税务居民身份及税务识别号码等相关资料。
5. 可以正常接收验证信息的手机和邮箱。

开户资格会受服务地区、身份和合规审核影响。不要把某一种证件可以上传，理解成所有地区居民都一定可以开户。

### 4、KYC 六个环节

如果此前已经完成平台 KYC，系统可能弹出信息同步授权。先核对证件是否有效、地址是否变化、地址证明是否仍在六个月内；有变化就更新资料，不要把旧认证直接当作证券开户审核结果。

#### 第一步：个人基本信息及身份认证

按证件填写姓名、出生日期、证件类型、证件号码、国籍等信息。姓名拼写和证件内容保持一致，不要使用昵称。

拍摄证件时使用实体证件原件，保证四角完整、画面清楚、没有强反光或遮挡。系统识别后，检查自动填入的信息是否正确。

#### 第二步：居住地址及地址证明

填写实际居住地址、城市、邮编等信息。地址要与证明文件对应。若页面要求英文地址，按照标准英文地址格式填写。

地址证明应显示申请人姓名和居住地址，文件日期需符合平台要求。上传前检查文字是否清晰、页面是否完整。

#### 第三步：财富及投资活动信息

根据真实情况填写职业、收入、资产、资金来源、预计交易金额等信息。不同字段的金额单位可能不同，填写前先看清楚单位和区间。

资金来源、财富来源和净资产信息应当能够相互对应。税务居民身份及税务识别号码按照真实情况填写，不要为了通过审核随意选择国家或填写不属于自己的号码。

#### 第四步：投资经验与风险评估

页面会询问股票、ETF、期权等产品的投资经验、交易年限、投资目的和风险承受能力。按照实际情况回答。过去只交易过加密资产，不代表有股票期权交易经验。

#### 第五步：阅读声明与协议

认真阅读证券账户协议、风险披露、交易及托管安排、收费和相关声明。确认理解后，再勾选对应项目。

#### 第六步：签名并提交

按照页面要求完成电子签名。当前个人账户指南要求使用英文字符签名，可按证件英文姓名或符合页面要求的姓名拼音填写，并与其他开户文件保持一致。提交前再次检查姓名、证件、地址、税务资料和上传文件。

开户入口及材料要求如有调整，以 BIT 当前开户页面及官方指南为准。

### 5、提交以后还需要做什么？

提交资料后，查看页面显示的申请状态。资料提交成功只代表申请已送出，证券账户是否开通仍需等待审核结果。官方个人开户指南给出的通常处理时间为 **1—4 个工作日**，补件和个别审核情况可能影响进度。

如果收到补件通知，按要求补交清晰的证件、地址证明或其他资料。审核期间留意 App 通知和注册邮箱。

开户成功后，再进入证券账户进行入金。不要把平台注册成功、身份认证通过和证券账户开通混为一谈。

## 三、资金入账：银行电汇与稳定币

证券账户开好之后，如果你的资金已经在银行账户里，可以通过银行电汇转入 BIT。

银行电汇可以记成三步：**获取收款资料 → 本人银行汇款 → 回 BIT 提交通知和凭证**。如果资金主要是稳定币，可看本章后面的证券账户划转步骤。

### 1、银行电汇前：核对账户与币种

1. 使用**本人名下的银行账户**汇款，银行账户姓名需要与 BIT 证券账户姓名一致。指南显示暂不支持他人账户或第三方平台代为转入。
2. 确认汇款币种。美元入金选择美元通道，港币入金选择港币通道。
3. 每次汇款都从自己的 BIT 账户获取收款信息。收款账号、IBAN、SWIFT 代码和汇款备注以当次页面为准。
4. **汇款备注或 Reference** 用于识别证券账户，必须完整填写。

### 2、美元银行电汇

#### 第一步：进入美股账户，找到电汇入金入口

打开 BIT App，进入“美股”及“资产”页面，选择“资金划转”或“电汇入金”，进入美元收款信息页面。

#### 第二步：复制收款银行信息

页面会显示收款银行、收款户名、账号、SWIFT 代码、IBAN、银行地址及汇款附言等资料。指南示例中的收款银行为 Singapore Gulf Bank（SGB），收款户名为 Matrix Gelephu Pte Ltd，所在地为巴林麦纳麦。

实际汇款时不要直接照抄教程截图，应使用自己账户当次显示的收款信息。银行要求中间行信息时，也按照 BIT 页面提示填写。

#### 第三步：通过本人银行账户发起美元电汇

打开银行 App 或网上银行，选择国际汇款或电汇，按 BIT 页面提供的信息填写收款人、银行账号、SWIFT、地址、币种及金额。

特别检查**汇款备注、附言或 Reference**。漏填或填错，可能导致入账延迟或需要人工处理。

提交前核对收款户名、账号、币种、金额和备注，并查看银行显示的手续费。汇款完成后保存回单。

#### 第四步：返回 BIT，添加或选择汇款银行账户

银行端操作完成后，返回 BIT 的电汇入金页面，点击“我已转账”或对应的通知入口。如果尚未绑定汇款银行账户，按照页面提示添加；已经绑定的，选择本次实际汇出的账户。

#### 第五步：上传凭证并提交入金申请

上传银行回单，填写实际汇款金额及页面要求的汇款日期、参考编号等信息，然后提交入金通知。

如果分多笔汇款，应分别提交对应的通知和凭证，不要将多笔转账混成一笔申请。

对照下图时，重点看清**收款信息在哪里复制、银行卡在哪里绑定、汇款凭证在哪里上传**。银行汇款完成后，还要返回 BIT 完成通知。

### 3、港币银行电汇

港币入金按照港股入金指南操作：**证券资产 → 全部功能 → 电汇入金 → 港元（HKD）**。

进入港币收款页面后，复制对应银行资料，通过本人银行账户发起港币电汇。

指南建议优先通过 SWIFT 代码查找收款银行，再核对银行名称、所在地和其他资料，避免只凭名称搜索而选错银行。

汇款完成后，返回 BIT 添加或选择银行账户，点击“我已转账”，上传汇款凭证，填写金额并提交。

美元和港币的收款资料及附言可能不同，不能直接套用另一币种的截图。**港币入账不表示自动获得美股账户的美元购买力**；如需买美股，应先查看账户支持的换汇和划转安排。

### 4、稳定币：从主账户划转到证券账户

如果资金主要是 USDT、USDC，稳定币入金是 BIT 值得研究的另一个入口。官方资料说明，美股证券账户支持 USDT、USDC 转入和转出，并区分快速模式与普通模式。

> **充值后还要划转：**稳定币充值到 BIT 主账户，与划转到证券账户是两个环节。主账户显示资产，不代表证券账户已有可用于买股票的美元资金；是否完成入金，要看**证券账户到账记录和可用余额**。

操作前，按当前 App 页面依次核对以下信息：

1. 从外部钱包或交易平台充值时，收款币种、网络、地址以及需要填写的备注必须对应；不要只看“USDT”三个字就转账。
2. 主账户到账后，按 **“美股”→“资产”→“资金划转”或“稳定币入金”→“证券账户转账”**进入，选择 USDT 或 USDC，核对转出账户、转入账户和金额。
3. 查看实际兑换报价、预计到账金额、快速或普通模式的处理时间，以及确认页显示的全部费用。
4. 提交后查看划转状态，等证券账户显示可用资金再下单。若状态异常，先核查记录，不要反复提交同一笔操作。

两种模式的费用与处理方式分别看：

- **普通模式：**官方新手指南说明不收快速处理费，并支持按页面规则撤回或取消。
- **快速模式：**费用可能有活动减免，是否适用要看本次确认页。

预计入账时间以页面显示为准，“快速”不代表任何金额、任何时段都保证秒到。本文展示的是开户和银行电汇图解；稳定币的具体网络与收费以当前入金页面及官方指引为准，不套用港币账户的兑换费率。

## 四、注意事项：费用、到账与异常处理

### 1、电汇费用与预计到账

美元部分按银行电汇指引说明；港币部分按本系列的港股账户费用图整理，**港币收费不能直接套用到美元账户**。

### 2、汇款后还没到账，按顺序检查

1. **先看入金通知。**确认已在 BIT 提交申请并上传对应凭证；只有银行转账记录、平台端未提交的，先补齐这一步。
2. **再核对 Reference。**如果备注漏填或填错，联系 BIT 官方客服，提供证券账户信息和银行回单，协助匹配。
3. **超过预计时间再查汇款状态。**准备汇款日期、金额、币种、参考编号和回单，联系官方客服核查；必要时也向汇出银行查询。

**先查清原汇款状态，再决定下一步操作**，不要因为暂时没到账就重复汇出同一笔钱。

## 五、总结：确认账户和到账，再决定配置

对于手里本来就有稳定币、又希望增加美股正股和 ETF 配置的人，BIT 提供了一个可以研究的证券入口。但开户成功只是第一步，之后还要看清账户权益、资金划转和每笔交易的实际成本。

我建议先从自己能看懂的流程开始：资料如实填，收款信息从本人账户获取，到账后核对币种、金额和可用资金。把这几件事确认清楚，再按自己的投资计划决定配置多少资金。
