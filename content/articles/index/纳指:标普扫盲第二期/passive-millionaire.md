上次写完之后，我持续在评论区收集了一些问题，这里继续给大家做第二期答疑。今天的内容更加具体，从实际情况入手：每月有2000元或2万元，手上已经有100万元，买完又遇到下跌，分别应该考虑什么？

这些问题看起来是在问“买多少”，但只给一个金额，还不足以决定仓位。同样有100万元，一个家庭下个月要付首付，另一个家庭是十年内不用的长期资金，安排当然不能一样。

**这一课关注如何让投资计划适应自己的生活。** 建仓方式还不清楚的朋友，先读[第一期问答](/articles/index/iAj0LfIU)；已经开始投资的朋友，可以直接从目录找到自己的问题。

## 一、不同金额，先按用途分，再谈投资比例

### 1. 每月有2000元可以投资，应该如何安排？

先确认这2000元是扣除生活支出、短期目标储蓄和必要保障后的结余。如果只是“月底还剩这么多”，而下个月可能有一笔大支出，就不一定全部适合进入股票基金。

对于可长期投入的部分，保持产品简单确实有价值。但“买得少”不等于“全部重仓纳指”。你仍需要选择自己能承受的股票比例，以及更集中或更广泛的指数暴露。

也不要为了分散，买五只跟踪同一个指数的基金。不同基金公司的名字，可能对应高度重复的持仓；要看底层资产，而不是基金数量。

一年能投入多少，可以根据预算安排；一年能赚多少，却不能提前确定。月月投入的资金分批进入市场，不能把全年本金直接乘一个历史年化，当作当年的收入。

### 2. 每月有2万元，是否应该按固定比例分配纳指和标普？

金额增加，并不会自动告诉我们收入水平、家庭责任和承受能力。它可能是工资结余，也可能是奖金、经营现金流或暂时不用的钱。

这时候更值得做的是给资金分层：近期支出、应急与负债安排、长期投资。然后才在长期投资部分讨论股票、债券等资产比例。

纳指和标普500之间有不少成分重叠。按某个比例各买一只，可以改变组合风格，却不等于已经完成跨资产分散。不能仅因为每月有2万元，就机械安排“1.5万纳指、5000元标普”。

如果某只基金限购，也不要为了尽快把额度打完而换成完全不同的产品。限购是通道条件，不应该反过来决定你的资产配置。

### 3. 已经有100万元，应该一次买完吗？

先把“有100万元”和“有100万元可承受股票波动的长期资金”分开。短期买房、经营周转或家庭备用金，不会因为暂时闲置就变成长钱。

若确认是长期投资资金，再比较一次投入与分批投入。前者更早承担完整市场风险，后者可以降低刚投入就遇到下跌的心理压力，但会留下资金等待的机会成本。

可以做一个直观的压力计算：如果100万元全部属于股票资产，回撤40%时账面减少40万元；如果只有其中40万元配置股票、其余60万元假设价值不变，同样股票回撤对应总资产减少16万元。这是**情景计算，不是配置建议**，现实中其他资产也可能波动。

先看自己能否承受这样的金额，再确定股票比例和投入节奏。不要因为钱已经在手上，就觉得必须立即用完。

## 二、投资服务生活，用钱与退出也要提前安排

### 4. 一直不卖，钱放在里面有什么用？

赚钱的目的就是为了改善生活，在一定程度上，生活是第一位的。

前面讨论长期持有，是为了避免凭短期情绪频繁进出，不是要求永远不能用这笔钱。教育、住房、退休支出等目标接近时，需要提前安排流动性，逐步降低必须使用资金的市场风险。

如果赎回的是 QDII，还要留意开放日和到账时间。不要等到付款前一天，才发现资金尚未到账。

另一种退出理由是资产比例偏离了原计划。例如股票上涨后占比明显高于自己设定的范围，按计划再平衡，与“感觉明天要跌所以先卖”是不同的决策。

### 5. 境外证券账户里的产品，一定比境内更好吗？

产品可能各有优势，但要把完整成本算在一起：基金持续费用、买卖佣金、换汇价差、汇款及中转费用、税务处理和账户维护。

不能把某只低费率标普 ETF 的费用，当作所有境外 ETF 的费率；也不能把所有境内产品的费用写成一个数字。比较时必须是同一个投资目标、相同持有期限与可执行的资金安排。

没有一个通用的“超过50万元才值得出海”门槛。每月小额投入与已有合法境外资金，面对的固定成本不同；账户资格也不由资金数额单独决定。

准备比较账户时，可以进入[美股账户准备与入金系列](/articles/series/us-stock-funding)。先核对自身条件，再看开户教程。

### 6. 黄金可以作为组合的一部分吗？

我对黄金持保留态度，但个人偏好不能代替对产品特点的理解。讨论它是否适合自己的组合，需要先看它提供什么、又不提供什么。

黄金不像企业股权那样依赖经营利润和分红，也不提供债券式的固定票息，价格仍会波动。考虑它时，应先说明它在组合里的用途，而不是看到一段时间上涨，就拿它替换原来的全部计划。

实物黄金、黄金基金与带杠杆的衍生品，又是不同的工具。这里只把问题放回资产配置中，不延伸成一份当前黄金买卖判断。

## 三、下跌之后，检查计划比证明自己正确更重要

### 7. 刚买入就遇到大回调，应该怎么办？

首先把“账面亏损让我不舒服”和“这笔钱马上必须用”分开。前者需要检查风险承受能力，后者可能说明投入时就有期限错配。

可以按顺序检查：家庭现金流有没有变化，持有产品是否仍跟踪原来的目标，股票比例是否超出计划，以及是否使用了借款或杠杆。再根据这些变化决定继续、暂停新增投入或降低风险。

不要用“亏了不卖就是价值投资”判断对错。低位被迫卖出当然可能损失很大，但不断加仓也不是证明信念的考试。指数长期发展有其基础，却没有按时回本的合同。

尤其不能把房屋抵押、消费贷款或融资借款简单接到定投计划上。借款有还款时间，市场恢复没有约定日期；融资账户还可能面临追加保证金或被迫平仓。需要先解决资金结构，而不是用“长期看好”覆盖它。

### 8. 为什么场内、场外涨幅不同，要换吗？

先核对比较口径：是不是同一个指数、同一日期、同一币种、相同分红处理？再区分场内成交价变化和基金净值变化。

联接基金的现金仓位、基金费用、跟踪方法可能造成差异，场内价格的折溢价也会造成差异。这不支持“场内长期一定更高”的结论。

要换产品，先把旧产品退出费用和新产品进入成本算一遍。一个阶段涨得慢，不一定值得立即切换。具体比较方法见[场内与场外基金怎么选](/articles/index/26IkwBvR)。

## 四、定期检查时，别只盯着累计盈利

### 9. 10万元按年化10%放20年，最后有多少？

在**没有追加和取出、按固定10%年回报进行复利演示**的假设下，计算公式为：

**期末价值 = 100000 ×（1 + 10%）的20次方 ≈ 67.27万元**

这是数学结果，不代表存在一款每年稳定支付10%的指数产品。真实收益会波动，费用、税收、通胀及汇率都会影响最终可用财富。

如果改成4%或7%的假设，20年后的结果分别约为21.91万元、38.70万元。假设稍微变化，长期结果就差很多。完整的投入与目标测算放在[复利与定投计算](/articles/index/uikdmSlX)。

### 10. 持有场外基金，应该定期检查哪些指标？

我会把检查顺序放在“还适不适合自己的计划”上，而不是只看过去一年涨了多少：

| 检查项 | 要回答的问题 |
| --- | --- |
| 标的与规则 | 跟踪指数、份额类别、投资范围有没有变化 |
| 费用与跟踪 | 实际费用如何，同口径的净值与基准表现差距怎样 |
| 规模与运作 | 是否有影响持续运作的公告，不能只凭规模大小判断安全 |
| 开放与限购 | 定投能否继续，确认和赎回规则是否调整 |
| 自己的现金流 | 收入、负债、用钱时间是否变化 |
| 组合比例 | 是否过度集中在重复资产，需要按计划再平衡吗 |

限购额度属于会变化的业务信息，不能把旧文章里的“每天能买多少”当作当前规则。如果计划扣款失败，先查公告与交易记录，不要仅为买得到就转向高溢价场内产品。

## 五、比例会漂移，但调整不是保证收益的魔法

![预算、投入、记录、定期复核和调整形成长期计划闭环](/images/articles/etf-learning/plan-loop.svg)

流程示意：检查可以有固定节奏；调整依据资金条件和事先规则，不是每次价格变化都交易。

再平衡，是当资产比例偏离预先设定的安排时，按规则进行调整。它的主要作用是管理组合暴露，不保证每次都提高收益。卖出上涨资产、买入相对落后资产，后续可能继续与价格趋势相反；费用、税务和交易条件也会影响结果。

资料：[Wise Invest：纳指 / 标普投资白皮书（概念、收益与产品结构章节）](https://www.wise-invest.org/book/nasdaq)

虚构例子：组合100元，股票60、现金40。股票上涨25%，变成75，现金仍40，总额115，股票占65.22%。若仍以60%为目标，股票应为69、现金46，需要从股票转6元到现金。60/40只是计算示例，不是个人配置建议；现金不变与忽略费用同样是简化假设。

再平衡也可以先使用新增资金，而非每次卖出。按较低权重的一侧投入，有机会减少交易，但能否恢复目标取决于结余金额与偏离程度。执行规则可以按时间或偏离阈值安排，选择哪种方式需考虑复杂度和成本。没有必要频繁把每个小数位恢复到原样。

更重要的是区分比例漂移与目标变化。市场涨跌造成权重变化，可以按既定规则检查；收入、家庭支出或使用时间改变，则可能需要重新设计目标本身。不能用原比例约束已经不同的生活条件，也不能把临时看空情绪包装成理性的长期目标更新。

## 六、写下来，下一次行情变化时才有东西可以对照

模板供填写，不预设金额、比例和收益率。

| 项目 | 你需要写的内容 |
| --- | --- |
| 目标 | 这笔资金最终用于什么，预计何时使用 |
| 边界 | 必要支出、储备、债务与可承受损失 |
| 资产 | 每类敞口的用途，以及与已有资产的重叠 |
| 产品 | 完整身份、基准、费用、渠道与退出 |
| 投入 | 资金来源、金额、频率与异常订单处理 |
| 检查 | 固定复核时点、比例偏离与数据核验 |
| 调整 | 收入或用途变化时的暂停、修改条件 |
| 退出 | 用钱前的风险与到账安排 |

填完后，让每个字段都能被未来的自己理解。‘适当控制风险’太模糊，可以改成哪些钱不进入风险资产、哪个现实条件需要复核；‘长期投入’太宽，可以写明预算来源与确认频率。精确不等于预测数字越多，而是规则越能实际执行与验证。

记录也不必复杂。保留投入与取出、确认份额、费用、现金分配和重要调整原因，先让账本完整。一个无法解释的高年化数字，不如一份清楚的金额与日期记录。只要记录能回答钱在哪里、计划是否执行、哪些条件变化，它就发挥了核心作用。

## 七、把持有变成定期复核，而不是每天重新下注

个人觉得，在不同阶段，要根据实际情况作出属于自己的投资选择。这个“实际情况”，包括市场，也包括自己的工作、家庭和现金流。

可以选一个固定的复核时间，把投入记录、产品公告、资产比例和近期用钱安排放在一起看。没有发生影响计划的变化，就不必因为每天的报价反复推翻决定；发生了变化，就如实调整，而不是为了坚持一个口号硬扛。
