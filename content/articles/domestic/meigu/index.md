想投资美股，最容易卡住的，往往不是“买哪家公司”，而是前面的几个问题：我要先开香港银行卡吗？有了银行卡，钱怎样到券商？已经有 USDT，还要不要再绕一圈银行？币安里的股票，和 BBAE、BIT 里的股票又是不是一回事？

我们之前分别写过银行、券商和交易所教程，但分开看，很容易把每个产品都研究了一遍，还是没有接成一条能实际执行的路线。

这篇就把它们串起来。你可以先选一条适合自己条件的路，再沿着**账户准备 → 资金到账 → 买入证券或对应产品 → 卖出与出金**往下走。每一步需要的详细教程，都放在相应位置。

> **开户只是其中一步。**一条可以长期使用的投资路径，要同时回答：我买到什么、钱从哪里来、怎样成交、将来怎样把资金转回来。

## 一、先选路线：你买到的究竟是什么

### 四条路线，解决的是不同起点的问题

下面按大家接触产品的方式来分。这里的“港资、美资、BIT、交易所”是阅读入口，**不是四种互不重叠的法律类别**；签约实体、证券托管和持有权利，还要看具体账户协议。

| 路线 | 资金怎样进入 | 下单前要确认什么 | 本文对应部分 |
| --- | --- | --- | --- |
| 港资券商：复星、致富、腾达等 | 本人银行账户 → 券商支持的入金方式 → 对应交易币种 | 美股权限、美元余额、换汇与订单费用 | 第三部分 |
| 美资券商：盈透、BBAE、嘉信、第一证券等 | 券商接受的本人银行账户 → 电汇或可用的其他方式 | 实际开户实体、收款资料、资金可交易状态 | 第四部分 |
| BIT 证券账户 | 本人银行电汇，或支持的稳定币转入及证券账户划转 | 证券账户是否开通、实际入账币种与可用资金 | 第五部分 |
| 加密交易所里的股票相关产品 | 按具体产品要求准备资产，必要时另开证券子账户 | 是证券、股票代币还是合约，以及本人是否有权限 | 第六部分 |

如果你只想用人民币配置纳指或标普指数，**不一定需要先开境外银行和证券账户**。支付宝场外基金、国内券商场内 ETF，是另外一条完整的基金投资路径；买到的是相应基金份额，不能和直接持有美国上市股票混为一谈。关于这些入口，我们已经单独整理：

### 先画自己的路线，再决定开哪些账户

可以先在纸上写一句话：**“我准备用已有的什么资金，通过哪个本人账户，购买哪一种资产。”**

例如，已有可用于投资的境外银行美元资金，就从传统券商的收款方式往前检查；已有符合使用条件的稳定币，可以研究 BIT 或交易所内的具体产品。手里只有境内人民币，也没有已确认可行的境外投资资金安排，就先看人民币基金路线，不把“找一个中转账户”当成解决全部条件。

### 银行账户负责转账，卡片负责什么要另看

### 钱怎样先进入银行，再进入券商

银行账户开好后，先从本人 App 查看**账户已激活、收款姓名、账号、支持币种和转账限额**。如果接收自己的合法收入、同名账户转账或其他获准资金，按真实来源保留相应凭证；需要跨境汇款时，另核对汇出行、收款行和资金用途要求。

这里尤其要讲清楚：个人购汇便利化额度不是境外证券投资额度。外汇局的[个人外汇管理问答](https://www.safe.gov.cn/neimenggu/file/file/20200228/fa90770027ed4d919de981c09bc25751.pdf)列明了购汇用途限制。**开好香港银行卡、经过支付账户或换成稳定币，都不会自动改变原有资金用途规则。**本文后续资金步骤，以本人已经具备符合要求的账户、资金及使用资格为前提。

资金到了银行，也还没有进入证券账户。实际汇款可以按下面的顺序做：

1. **先到券商找入金指引。**选币种和转账方式，需要建立入金通知的先完成通知；通知本身不等于已经转账。
2. **复制本次收款信息。**核对收款户名、账号、银行代码及专属附言；证券机构的收款户名未必是你的姓名，同名要求通常指汇出账户与你的证券账户相匹配。
3. **回本人银行发起汇款。**选择对应通道，填真实用途，检查汇率、手续费、预计到账和附言。
4. **保存回单，再回券商核对。**需要上传凭证的及时提交；查看的是证券账户入账记录及可用资金，不只是银行“已汇出”的提示。

> **先确认两端，再转钱。**银行支持某个币种，不代表券商接受同币种的所有汇款方式；手机截图中的账号与附言也不能直接照抄。

## 三、港资券商：从香港银行到美股账户

### 以复星为例，把开户与入金接起来

这条路线可以记成：**本人银行资金 → 复星证券账户 → 美元资金或所需换汇 → 美股订单**。致富、腾达等券商，也应分别检查这几个环节，不能直接照抄另一家券商的收款资料。

首先准备真实的证件、地址、税务居民及财务资料，申请证券账户，并确认所需的美股交易权限。复星使用星财富入口；账户申请通过以后，再进行资金操作，不把平台注册成功当作证券开户成功。

使用 Wise 渠道申请复星时，在注册阶段确认邀请关系。已确认的渠道权益是：**入金等值 10,000 港币，解锁免佣**。这里的免佣指对应佣金项目，不能理解为换汇、平台费和全部交易费用都取消。

资金到账之后，重点做三件事：

- **看币种。**港币现金不等于美元现金；准备买美股时，检查是否需要兑换、是否支持自动换汇，以及确认页是否会产生美元借款。
- **看权限。**进入美股市场，搜索证券代码，确认买的是股票或 ETF；期权和其他衍生品不是同一个产品。
- **看订单。**确认方向、股数或金额、订单类型、价格和有效期，再提交；到订单记录核对是否成交。

复星[官方股票产品说明](https://www.fosunwealth.hk/zhCn/stock)介绍了港美股及相关订单功能。页面上的“可以买”和“可融资”，也不是同一个意思；如果这次只是用自有资金买入，就要看懂实际现金和融资状态。

## 四、美资券商：盈透、BBAE、嘉信与第一证券

### 先选账户，再按该账户的指引准备资金

美资券商这一条，核心仍然是**本人银行账户 → 券商接受的资金通道 → 证券账户 → 股票或 ETF**。品牌来自哪里，不等于每位用户都签约同一个实体；例如盈透的实际服务主体要看开户协议。

选券商时，至少把这四项放在一起看：是否接受本人的真实居住地和资料、是否支持所需证券与交易功能、自己的银行能否按要求汇款、长期费用是否适合自己的交易金额。

### 以 BBAE 为例：注册、汇款、确认资金

BBAE 的教程把平台、经纪商与清算机构的分工一起讲了。决定申请以后，在 App 注册环节填写邀请码，再提交开户资料。

> 注册 BBAE 账户 · 邀请码：**stiibsmu3** · 福利：首次入金 2,000 美元，领取 20 美元奖励

这里保留的是 Wise 已确认的渠道条件：**首次入金 2,000 美元，领取 20 美元奖励**。奖励不是投资收益，也不应为了达到活动门槛，转入超出自己原定计划的金额。

账户获批后，在 BBAE 资金页面选择自己的实际入金方式。使用国际电汇，就从当前页面获取银行资料及本人账户识别信息，通过同名银行账户汇出；提交以后，等待券商入账并检查可用现金。ACH 则要满足相应银行与绑定条件，不能把任意境外银行账号都填成美国 ACH 账户。

**已有其他券商资产时，“转仓”和“银行入金”也要分开。**转仓可能涉及证券持仓、现金、资产支持范围及转出费用，不是给银行卡换一个收款账号。BBAE 的[入金 FAQ](https://www.bbae.com/faq/account-funding/)分别说明了这些方式。

### 以盈透为例：入金通知不是汇款本身

盈透的[官方资金说明](https://www.interactivebrokers.com/campus/trading-lessons/cash-and-position-transfers/)会按账户、币种和地区展示可用方式。使用银行转账时，先在资金转入页面建立通知、取得收款指引，然后去银行真正执行汇款；只建通知，余额不会自动增加。

到账后还要分清**账户汇总显示币种、实际持有的现金币种与交易购买力**。不要因为资产页面以美元展示总值，就以为所有余额已经完成换汇。后面的订单核对同样适用于这类账户。

## 五、BIT：银行资金与稳定币怎样进入证券账户

### 先开证券账户，不只注册主账户

BIT 值得单独讲，是因为它把银行资金和稳定币入口连接到证券账户。研究它时，要把**平台主账户、证券账户和证券资产**分开，而不是把“能充 USDT”直接理解为“股票已经在链上”。

如果从港币入金，要先看港币资金及换汇安排。BIT 的[港股资金说明](https://www.bit.com/helpcenter/articles/17455409)区分 HKD 入账与 USD/HKD 兑换；**港币到账不等于已经得到美股可用的美元资金**，银行与中转行费用也要计入。

### 稳定币入金：充值与证券划转是两次操作

这条路径是：**支持的稳定币进入主账户 → 划转至证券账户 → 核对证券资金 → 下股票订单**。

1. 从外部转入时，逐项核对币种、网络、地址和必要备注，先确认该网络是当前收款页面支持的网络。
2. 主账户到账后，进入美股资产里的资金划转或稳定币入金，选择证券账户转账。
3. 按页面选择 USDT 或 USDC、转入金额及快速或普通模式，查看实际兑换结果、费用和处理安排。
4. 提交后查看划转记录，确认证券账户可用资金增加，再进入股票页面。

这些环节依据 BIT 的[稳定币入金指南](https://www.bit.com/helpcenter/articles/13972370)。主账户显示资产、证券划转处理中、证券账户可交易，是三个不同状态。

到实际买入时，在证券产品页核对股票或 ETF，再填写订单；市价与限价的区别放在第七部分统一演示。BIT 的[订单说明](https://www.bit.com/helpcenter/articles/15899464)也分别解释这两种方式，不能从稳定币充值流程推导股票订单会自动完成。

## 七、第一笔订单：从搜索代码到确认成交

### 用一笔限价买单，走完证券交易流程

开户与入金文章看完以后，真正需要补上的就是这一步。下面以**普通股票或 ETF 的现金买入订单**为例；不涉及期权、保证金借款或永续合约，也不代表推荐某个标的或买入时点。

先找证券代码，再同时确认公司或基金全名、上市市场、币种及产品类别。同样的公司名字，搜索结果里可能有股票、期权、代币和杠杆产品，不能只看图标。

实际入口可以参考两家券商的官方操作：

| 账户 | 已公开的订单入口 |
| --- | --- |
| 盈透网页端 | Trade → Order Ticket → 搜索并选择证券及账户 → Buy → 填写数量、类型、价格和有效期 → Preview → Submit |
| BBAE | Watchlist 或搜索证券 → Buy → 填写数量、订单类型与价格 → 复核并提交 → Orders 查看结果 |

入口依据：[IBKR Order Ticket](https://www.ibkrguides.com/clientportal/trade/trade-button.htm)、[BBAE Trading FAQ](https://www.bbae.com/faq/trading/)。App 版本可能调整按钮位置，但订单里需要核对的内容不会因为换个界面就消失。

假设只是演示操作：你希望买入某只证券 **2 股，每股最多愿意支付 100 美元**。那么可以这样理解订单字段：

| 字段 | 本例填写或检查的内容 |
| --- | --- |
| 买卖方向 | Buy／买入 |
| 数量单位 | 2 股；先确认输入框不是“投资金额” |
| 订单类型 | Limit／限价单 |
| 限价 | 100 美元／股 |
| 预计占用 | 成交本金最高 200 美元，另计实际费用；预留足够可用资金 |
| 有效期与时段 | 检查 DAY／当日等选项，并确认是否仅在常规交易时段执行 |
| 提交前预览 | 再看一遍证券、方向、数量、金额与费用 |

这笔买单只接受 **100 美元或更低**的成交价，但不保证成交，也可能只成交一部分。市价单则不锁定最终价格，看到的最新成交价不等于你的实际买入价。两者的核心区别见 [Investor.gov 订单类型说明](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)。

### 提交以后，必须再看订单结果

“订单已提交”只是平台收到了请求。你还要进入订单记录，看它现在处于什么状态：

- **待成交或已接受**：仍在等待执行，不代表已经持仓。
- **部分成交**：记录实际成交股数与均价，剩余部分可能还在等待。
- **全部成交**：核对成交数量、平均价格、费用与持仓增加是否一致。
- **拒绝或取消**：先看原因；申请撤单以后，也要确认最终状态，不能把“撤单申请已发出”当作已经撤掉。

BBAE 的交易说明明确，已经执行的订单不能再撤销。不要因为页面刷新慢就重复点击买入；先查看订单号、成交记录和持仓，避免把同一笔计划下成两单。

> **第一次操作的验收结果，是你能解释清楚这张订单。**买的是什么、花了多少、成交多少、还剩多少现金，比只看到一条“提交成功”更重要。

## 八、卖出与出金：把资金回程也走通

### 卖出成交、资金结算、银行到账是三个时点

卖出时，从本人持仓进入对应证券，核对可卖数量，选择卖出订单并查看成交结果。不要把原本的“减少持仓”误操作成新增其他产品或开立空头仓位。

大多数美国股票交易采用 **T+1 结算**，即交易日后的一个营业日完成交收；这不等于每笔卖出款在第二个自然日就一定能到账银行。入金冻结、账户审核、币种兑换、提现处理与银行营业时间，可能另占时间。结算概念见 [Investor.gov 的 T+1 说明](https://www.investor.gov/introduction-investing/investing-basics/glossary/settling-securities-transactions-t1)。

| 你采用的路线 | 卖出以后继续检查 |
| --- | --- |
| 港资／美资券商 | 已结算资金、可提取金额、收款银行资格、提取币种及费用；提交后核对券商记录和银行实收 |
| BIT 证券账户 | 先核对证券账户可转出资金，再按本人页面选择支持的银行或稳定币路径；不把证券卖出自动等同主账户已到账 |
| 交易所证券子产品 | 按该产品规则检查结算及资金账户；例如币安证券卖出款以 USDC 进入资金账户，可转出状态仍要单独查看 |
| 代币化股票 | 区分平台卖出、转币和向发行方赎回；各自的开放条件、网络与费用不同 |

币安证券的资金处理见其[结算与卖出资金说明](https://www.binance.com/en/support/faq/detail/7ae9ef8636e74e8b9c3b625677b83310)。

以 BBAE 为例，可以从 **Account → Withdraw** 进入，选择已绑定的收款账户，核对金额和费用后按提示提交。其[出金 FAQ](https://www.bbae.com/faq/withdrawals/)还规定了首次入金后 60 天内提回原入金银行的要求。提交后继续检查提现记录及银行实收，不把“提现申请成功”当作银行已经到账。

这也是为什么**要在入金之前先看一次出金规则**。

如果不确定钱停在哪一步，下面的基础课用资金账本与排查表，把银行汇出、券商入账、交易结算和银行实收分开说明：

[资金入账与结算](/articles/domestic/QKEIghQr){card}

### 把成本算完整，不只看“零佣金”

一条路线的成本，可以拆成：**资金转入费用 + 换汇成本 + 买卖费用 + 持有期间费用 + 转出成本**。并不是每笔都有全部项目，但不能只拿宣传中的一项费率作比较。

例如，仅作算术演示：如果每次固定汇款费是 20 美元，汇入 500 美元时，这一项就占 4%；汇入 5,000 美元时占 0.4%。所以小额、频繁投资时，资金通道的固定成本可能很显眼。这个例子没有代入任何一家银行的现行报价，也不是建议为了摊薄费用增加投资金额。

最后给自己留一份可以核对的记录：开户协议、资金来源材料、汇款回单、成交单、账户月结单和适用税务资料。开户实体、银行所在地或使用稳定币，不会自动免除本人应承担的申报义务。

### 选定一条路，按阶段完成

| 当前进度 | 下一步 |
| --- | --- |
| 还没有确定资产类型 | 回到第一部分，分清证券、基金、代币和合约 |
| 已确定券商，但没有可用资金路径 | 先核对收款要求，再看第二部分的银行与账户教程 |
| 账户已获批，资金还在银行或主账户 | 对照对应路线，完成汇款、入金通知或证券划转 |
| 证券账户已有可用资金 | 按第七部分核对订单，提交后检查成交与持仓 |
| 已经持有，希望以后能顺利退出 | 提前看结算、可提取金额、收款账户及费用，保留交易记录 |

到这里，银行、券商、BIT 和交易所就不再是几个互不相关的 App，而是不同资金条件下的一组选择。**你不需要把所有产品都开齐；先把自己选定的那条路线，从资金进入到资金退出理解完整，再决定是否需要增加其他账户。**
