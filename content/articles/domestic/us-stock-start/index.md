## 一、先找到自己的起点

想开始投资美股时，最容易遇到的问题，往往还不是选哪一只股票，而是：我要先开银行卡，还是先开券商？没有港卡能不能开始？已经有稳定币，是不是就可以直接买了？

这些问题放在一起看会很乱。把过程拆开，其实是在解决三件事：**资金放在哪里，用哪个账户买，买完以后怎样卖出并取回资金。** 这一篇先用文字把顺序理清，具体的开户页面、入金操作和产品选择，留到系列后面的教程。

**按你现在的情况，找到下一步：**

| 你现在有什么 | 下一步先确认什么 |
| --- | --- |
| **只有境内人民币，还没有境外账户** | 先分清想配置纳指、标普基金，还是直接持有美股；再了解对应账户与资金条件。 |
| **已经有港卡** | 核对目标券商是否接受这家银行、对应币种与同名汇款，再选择证券账户。 |
| **已有其他境外银行账户** | 先查现有银行与目标券商能否衔接，以及费用和回款安排，再判断是否缺少其他账户。 |
| **已经持有 USDT、USDC 等稳定币** | 先区分证券账户、股票代币和合约，再确认本人资格及资金进入方式。 |

## 二、三个账户角色，解决三件不同的事

**银行账户负责存取与转账。** 它可以接收资金、兑换支持的币种，再按照收款方要求汇出。日常说的“开港卡”，在这个流程里更关键的是取得相应银行账户与转账功能；塑料卡片本身不是购买美股的凭证。

**支付账户负责特定的收付款与换汇服务。** 它可能提供多币种余额、收款资料或消费卡，但不能只看见银行名称，就当成自己直接在那家银行开了存款账户。以 Wise 为例，官方介绍的是多币种账户与支付功能，可用服务还要看地区与账户条件。[Wise 账户说明](https://wise.com/help/articles/2897226/what-is-a-wise-account)

**证券账户负责证券交易和持仓记录。** 买入哪只股票或 ETF、成交了多少、持有哪些证券、卖出后剩多少现金，主要在这里核对。港资、美资是理解券商背景的一种分类，实际账户仍要看签约实体、开放市场与本人资格；“港资券商”不等于只能买港股。

交易所则是另一个入口。里面可能同时有数字资产交易、股票代币、合约，以及另外申请的证券服务。不能因为这些功能在同一个 App，就把账户、资金和资产权利视为同一回事。

理解分工后，再看所谓“中转”就容易了：它只是资金先经过一个账户，再转到另一个账户。**每多经过一站，就多一次币种、费用、户名和用途核对。** 已有账户能直接完成允许的转账时，不必为了流程看起来完整而增加中间一站。

## 三、传统路线：银行账户怎样接上券商

大家熟悉的传统方式，可以写成这样一条顺序：

**确认开户资格与资金用途 → 准备本人银行账户 → 开立证券账户 → 按券商收款要求入金 → 确认购买力 → 下单并检查持仓。**

香港银行账户是常见的衔接方式之一，但并非每条路线都必须经过香港。也有人使用自己符合条件的其他境外银行账户；是否可行，要看两端支持的汇款渠道、币种、户名与用途要求。

银行与券商的申请有时可以并行，学习上却应该先弄明白两端怎么接。比如，你已开好一个证券账户，但现有银行无法完成它接受的入金方式，单独拿到登录账号仍没有解决买入的问题。

入金时，先在本人证券账户里取得收款资料，再按要求从自己的资金账户发起转账。收款银行、收款人、账号、币种以及备注各有作用：有的识别收款机构，有的帮助机构把钱记入你的证券账户，不能直接照抄他人的截图。

也不要把“银行显示汇出”当作“券商已经可以买”。中间还有收款、匹配、入账和可用资金确认。IBKR 的官方入金说明也分别解释了资金可交易与可提取的等待期，并提示其通常拒绝第三方入金。[IBKR 入金说明](https://brokerage.ibkr.com/en/support/fund-my-account.php)

对新手来说，传统路线需要花时间理解银行与券商的衔接；优势是可以沿着银行记录、入金记录、订单与持仓逐项核对。选账户时，除了开户难度，也要把后续重复转账和退出的便利程度一起考虑。

## 四、数字资产路线：C2C 之后还有哪些步骤

现在另一类常见讨论是：通过交易所准备稳定币，再参与与美股相关的产品。这条路线改变了资金进入的方式，但没有省掉确认账户资格和资产性质这两步。

先解释 **C2C，也常写作 P2P**。在这类交易里，用户通过平台与另一位用户交易数字资产；你按订单付款，对方完成放币后，你获得的是对应的数字资产。币安的官方定义也是用户之间的加密资产交易，并不是直接购买股票。[P2P 交易说明](https://www.binance.com/en/support/faq/detail/360038038972)

因此，完整顺序应该写成：

**确认当地规则与服务资格 → 开立并验证交易所账户 → 通过可用且允许的方式取得数字资产 → 确认目标产品与资金划转要求 → 完成相应账户审核或转换 → 下单。**

C2C 只是可能的资金入口，已经持有稳定币的人未必需要这一步；并非每个地区、每家平台都开放同样的服务。交易所可以注册，也不代表它里面的证券服务一定向你开放。

接下来会出现两种重要分支。

**一种是把稳定币资金转入证券服务。** 例如 BIT 的美股服务设有独立的稳定币入金流程，需要在股票账户里发起相应划转。资金来源可以是稳定币，但仍要完成证券账户的要求，最终查看的是证券账户里的资金与持仓。[BIT 稳定币入金说明](https://www.bit.com/helpcenter/articles/13972370)

**另一种是买与股票价格相关的代币或合约。** 这时即使名称里出现某家美股公司，也不能直接等同于持有那家公司的股票。比如 OKX 的代币化股票说明区分了价格敞口与底层股票所有权。合约还需要另外理解保证金、资金费和强平机制。[OKX 代币化股票说明](https://www.okx.com/help/unified-tokenized-stocks)

所以，比较传统路线与数字资产路线时，先问两件事：**钱怎样进入？最后持有的是什么？** 用什么币种付款，不能单独回答你拥有什么资产。

## 五、用一笔投资把去程和回程串起来

假设你的目标是长期持有一只美国上市 ETF。先不考虑它未来涨跌，只看一次交易怎样完成。

第一步，确认目标是证券账户里的 ETF 份额。然后根据自己已有的银行资金或稳定币，挑选本人能够使用、并支持该产品的账户路线。这一步决定的是账户与资产之间的关系，还没有开始下单。

第二步，把资金按接受的方式转入，核对到账币种和实际可交易金额。银行余额、交易所余额与证券购买力是三个不同的位置；余额出现在其中一个地方，不代表其他地方同步可用。

第三步，搜索并核对产品代码、上市市场和交易币种，填写数量与订单条件。提交订单后，再看是等待成交、部分成交还是全部成交；**提交成功不等于买入完成，最终要看成交记录和持仓。**

第四步，记录以后怎样退出。证券卖出后，通常还要经过结算，资金也可能有提取等待期。接着按账户支持的方式申请出金，核对收款账户和实际到账；如果路线涉及数字资产，还要分清证券资金退出、币种转换与银行收款这几个独立动作。

这样，一笔投资的完整流程就不是“开户后点买入”，而是：

**准备账户 → 资金入账 → 确认购买力 → 下单成交 → 核对持仓 → 卖出结算 → 资金取回。**

> 能说明资金如何进入、资产记在哪里、将来如何退出，才算把这条路线理解完整。先把每一步弄清楚，再决定投入金额。

## 六、这个系列按六部分往下学

《美股从 0~1 投资开户教程》会按下面的顺序展开。你现在读到的是第一部分，先建立完整认识，再进入具体操作。

**第一部分：理解整套流程。** 就是本篇。先判断自己属于没有境外账户、已有港卡，还是已有数字资产的情况，弄清账户分工和资金去向。

**第二部分：没有港卡时，先了解可选账户。** 分别阅读 Wise、iFAST、StarryBlu 等账户与服务的介绍。它们的性质、开户条件与首次资金进入方式不同；尤其有些操作示例本来就依赖已有港卡，不能把这一组理解成“没有港卡也都能直接完成入金”。已有港卡的人也可以按实际需求了解这些工具。

**第三部分：准备香港或其他境外银行账户。** 进入香港银行的具体开户教程，同时为华美银行开户保留一篇待补的独立教程。银行是资金路线中的选择，不要求按目录把每家都开一遍。

**第四部分：开立证券账户。** 分别了解港资、美资券商与 BIT 证券账户，核对本人资格、可交易产品以及接受的入金方式，再选择与现有资金条件能衔接的一家。

**第五部分：了解交易所入口。** 学习注册、身份验证和资金账户操作，理解 C2C 与币种划转的位置，并分清证券服务、股票代币与合约。只准备走银行与传统券商路线的读者，可以先把这一部分作为补充了解。

**第六部分：交易基础与完整流程。** 先用三篇基础课看懂账户余额与购买力、第一笔订单、资金入账与结算，再结合已有入金图解。最后一篇把前面的教程重新串起来：从资金进入，到第一笔订单，再到卖出和出金，逐项核对实际结果。

学习时可以收藏整个系列，再按自己的起点继续。已经完成的账户准备可以跳过，但不要跳过资金两端的核对；没有准备好的环节，就回到对应教程补齐。目标是建立一条自己能理解、能持续使用的投资流程。
